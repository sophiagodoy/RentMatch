Sobre o RentMatch

Uma ferramenta para apoiar decisões no mercado de locação residencial.

Nosso objetivo

O RentMatch tem como objetivo estimar um valor de aluguel considerado justo a partir das características estruturais e contextuais do imóvel.

Como funciona?

O usuário informa características do imóvel, como localização, metragem, número de quartos, vagas e taxas associadas.

Estimativa e classificação

A partir dessas informações, o sistema utiliza um modelo de Machine Learning para estimar um valor de aluguel e comparar esse resultado com o valor anunciado.

Após a comparação, a oferta pode ser classificada como:

Caro Preço Justo Oportunidade
Para quem é o RentMatch?

A solução foi pensada para apoiar inquilinos, proprietários e profissionais do setor imobiliário.

Onde o sistema atua?

O RentMatch tem foco no mercado de locação residencial da cidade de Campinas - SP.

Dados, tecnologia e transparência para uma avaliação mais objetiva.
